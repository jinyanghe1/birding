## 同日 13:02 续：eBird 浏览器自动提交

### 已交付
- **`bird ebird auto-submit`**：用 agent-browser 自动化提交 CSV 到 eBird
  - 流程：打开上传页 → 若需登录则提示手动登录一次 → 自动上传 CSV → 提交
  - 前提：agent-browser 已安装（实测 0.23.4 可用）
  - **只需登录一次**，之后会话保持，可反复自动提交

### 关键结论
- eBird 上传页需要登录态（CAS 单点登录）
- 浏览器自动化可以复用已登录的会话，比 API 提交简单（API 提交需要 locId）
- `agent-browser` 实测可用，但 `snapshot -i` 的元素引用是法语界面（Cornell Lab 的 CAS 登录页）

## 同日 15:17 续：eBird API 权限确认 + 地图修复

### eBird API 权限（实测确认）
| 功能 | 端点 | 实测 |
|---|---|---|
| 查地区最近观测 | `GET /data/obs/{region}/recent` | ✅ 有效 |
| 查地理范围内观测 | `GET /data/obs/geo/recent?lat&lng&dist` | ✅ 有效 |
| 查历史观测 | `GET /data/obs/{region}/historic/{y}/{m}/{d}` | ✅ 有效 |
| 查附近热点 | `GET /ref/hotspot/geo?lat&lng&dist` | ✅ 有效 |
| 查物种 code | `GET /ref/taxonomy/ebird` | ✅ 有效 |
| **提交 checklist** | `POST /product/checklists` | ❌ **404，不存在** |
| 查我的 checklist | `GET /product/checklists/{date}` | ❌ 404 |

**结论：eBird API 是只读的**，不能提交观测。要提交只能：
1. 网页手动上传（`bird ebird export` 生成 CSV → 手动上传）
2. 浏览器自动化（agent-browser，但被 macOS 弹窗拦截）

### 地图修复
**问题**：Leaflet 在 `display:none` 的容器里初始化会失效（容器宽高为 0）
**修法**：`initMap()` 先显示容器，再初始化，加 `invalidateSize()` 兜底
