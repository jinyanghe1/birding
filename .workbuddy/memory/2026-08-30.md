## 缩略图权限修复 + 百度地图瓦片

### 已修复
1. **缩略图 403**：Nginx 的 www-data 用户读不了 `/home/ubuntu/birding/data/thumbs/`
   根因：目录权限链（`/home/ubuntu` 是 750，www-data 进不去）
   修复：`chmod 755` 每一级目录 + `chown -R www-data:www-data thumbs/`
2. **百度地图瓦片**：换成 `maponline{s}.bdimg.com`（免 key，实测 200）

### 安全协议（长期记忆）
**上线的服务要严守网络安全底线**：
- 所有写操作必须有鉴权（已实现：API Key）
- 所有密钥/Token 必须放在 `data/secrets/` 或环境变量，不进 git
- 定期审查端口开放（只开 80/443/22）
- 定期备份数据（每天凌晨 3 点）

### 关键经验
1. **Linux 权限链**：`www-data` 要读 `/home/ubuntu/...`，每一级目录都要 `chmod 755`
2. **macOS tar 的扩展属性**：`._*` 文件是 macOS 的扩展属性，Linux 上会多出来，不影响功能
3. **百度地图瓦片免 key**：`maponline{s}.bdimg.com/tile/?qt=tile&x={x}&y={y}&z={z}&styles=pl&scaler=1`
