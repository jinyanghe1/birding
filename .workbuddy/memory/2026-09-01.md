### 关键经验
- **静态文件路由**：FastAPI 需要显式加 `@app.get("/manifest.json")` 等路由，不能自动服务 static/ 目录
- **systemd 环境变量**：`Environment=KEY=value`（不是 `export KEY=value`）
- **邀请码设计**：一次性，注册后立即失效（`invite_code=NULL`）

### 使用方式
- 家人注册：owner 点「邀请家人」→ 复制链接发给家人 → 家人打开填名字 → 自动拿到 API Key
- 上传：进「家庭相册」tab → 创建相册 → 批量上传
- 同步：`bird sync pull --album 1 --dir ./photos`（下载）/ `bird sync push --album 1 --dir ./photos`（上传）
