## OSM 地图迁移 + 开发规范沉淀

### 1. OSM 地图迁移（完成）
- **方案**：优先 OpenStreetMap（免 key），失败 fallback 到百度地图
- **实现**：Leaflet `tileerror` 事件监听，OSM 瓦片加载失败自动切换
- **优势**：OSM 完全免费，无需注册，无配额限制（公共瓦片服务器）

### 2. 开发规范（长期记忆）

**本地开发 → 测试 → 提交 → 部署**：
1. 所有代码先在本地开发 + 运行验证
2. 无问题后 commit（细粒度，一个功能一个 commit）
3. push 到 GitHub
4. 远程服务器用 git pull 更新（或部署脚本）
5. 部署后测试业务逻辑
6. 不正常 → git 回滚 + 重新部署

**安全协议**（延续）：
- 所有写操作必须有鉴权
- 密钥/Token 只存 `data/secrets/`，不进 git
- 定期审查端口开放（只开 80/443/22）
- 定期备份数据

### 3. 技术要点
- **OSM 瓦片**：`https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png`，免 key
- **Fallback 机制**：`tileerror` 事件 → 切换百度地图
- **Leaflet 初始化**：必须先显示容器再初始化（`display:none` 会失效）

## 同日 14:19 续：tab 全部不显示修复

### 根因
OSM fallback 代码里 `tileerror` 回调是同步函数，但用了 `await`，导致整个 JS 文件解析失败，所有 tab 都无法切换。

### 修复
`tileerror` 回调改为 `async ()=>{...}`。

### 验证
Playwright 测试：无控制台错误，地图 tab 正常显示（display: block，内容 5567 字符）。

### 关键经验
- **JS 语法错误会导致整个文件不执行**，不只是出错的那一行
- **`await` 必须在 `async` 函数里**，回调函数也要标记 `async`
- **Playwright 是排查前端问题的利器**：能捕获 console error 和 pageerror
