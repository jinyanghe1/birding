# 中长期规划：迁移到服务器 + 家庭共享

## 目标

把观鸟数据库从「个人本地工具」升级为「家庭共享平台」：
- 家人可以上传观鸟记录（网页表单或微信小程序）
- 整个网站作为家庭使用和分享的平台
- **不考虑多用户权限**（家人之间不需要隔离）

## 架构对比

| 方案 | 成本 | 复杂度 | 适用场景 |
|---|---|---|---|
| **GitHub Pages（当前）** | 免费 | 低 | 只读分享，不能上传 |
| **Cloudflare Pages + Workers** | 免费（10 万次/天） | 中 | 只读 + 简单表单提交 |
| **Cloudflare Pages + Workers + D1** | 免费（5GB 存储） | 中高 | 完整读写，推荐 |
| **Vercel + Neon Postgres** | 免费（500MB） | 中 | 完整读写，Neon 是托管 Postgres |
| **自建服务器（Mac Mini）** | 0 元（已有） | 高 | 完全控制，需要 24h 开机 |
| **腾讯云轻量服务器** | ¥24/月 | 中 | 国内访问快，需要备案 |

## 推荐方案：Cloudflare Pages + Workers + D1

**为什么**：
- **免费额度够用**：10 万次请求/天、5GB 存储（D1 SQLite）
- **不需要备案**（Cloudflare 全球 CDN）
- **家人上传**：网页表单 → Workers → D1，不需要登录态
- **离线可用**：Service Worker 缓存，没网也能看

**迁移路径**：
1. **阶段 1（现在）**：GitHub Pages 只读分享 ✅ 已完成
2. **阶段 2（下月）**：Cloudflare Pages + Workers，加「上传」表单
   - 上传接口：`POST /api/upload`（Workers 处理）
   - 存储：照片 → R2（10GB 免费），元数据 → D1
   - 识别：Workers 调外部 API（Claude/GPT-4V）或回传到本地模型
3. **阶段 3（可选）**：PWA（渐进式 Web 应用），支持离线查看

## 数据迁移

```bash
# 当前 SQLite → D1（Cloudflare 的 SQLite）
# D1 支持标准 SQL，schema 可以直接导入
wrangler d1 execute birding --file=schema.sql
wrangler d1 execute birding --file=data.sql
```

## 上传表单设计

```
┌─────────────────────────────────┐
│  上传观鸟记录                      │
│                                 │
│  [选择照片或视频]                 │
│                                 │
│  拍摄时间：[日期时间选择器]        │
│  地点：    [地图选点或输入]        │
│  鸟种：    [可选，留空自动识别]    │
│  备注：    [可选]                │
│                                 │
│  [提交]                          │
└─────────────────────────────────┘
```

**识别流程**：
1. 上传 → Workers 接收 → 存 R2
2. Workers 调 Claude API（Haiku，$0.25/M tokens）识别鸟种
3. 写入 D1，触发 Pages 重新构建（或前端轮询）

## 风险与限制

- **Cloudflare Workers 超时**：30 秒，大视频上传需要分片
- **D1 查询限制**：单次查询最多 1000 行，分页需要 cursor
- **国内访问速度**：Cloudflare 国内节点质量不稳定，可能需要备案+国内 CDN

## 备选方案：自建服务器（Mac Mini）

如果 Cloudflare 不够用：
- Mac Mini 已有（24h 开机）
- Tailscale 组网（家人手机加入）
- 本地 FastAPI + SQLite（当前代码直接用）
- 需要处理动态 DNS / 端口映射

**推荐先 Cloudflare，不够再迁 Mac Mini**。
