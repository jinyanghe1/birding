# 微信小程序发布全流程调研报告（观鸟相册小程序适用）

> **调研时间**：2026-10-14（规则时效性标注为「截至 2026-10」，微信规则近年变动频繁，正式操作前建议以官方页面实时内容为准）
> **用户背景**：个人（北理工学生 + 腾讯员工），无公司主体；已有 FastAPI+SQLite 后端，部署于腾讯云轻量服务器 124.223.171.149（裸 IP + HTTP，无域名）
> **目标产品**：家庭共享相册（多用户、上传照片、按用户/家庭组分类）+ 观鸟数据展示（物种墙/地图/图表）

---

## 0. 核心结论（先看这里）

1. **「家庭共享相册」如果做成多用户互相上传、互相可见，即构成 UGC，会被微信认定为「社交-笔记」类目——该类目个人主体不开放，必须企业/个体工商户主体**（官方服务市场答复原文：「涉及用户自行生成内容(文字、图片、音/视频)的记录、分享，属社交-笔记范畴，为个人主体小程序未开放类目，建议申请企业主体小程序」）。这是本项目最大的主体决策点。
2. **可行的折中方案**：若相册改为「仅管理员（你）上传照片，家人只浏览/下载/保存」，不构成 UGC，个人主体即可上线（选「工具-图片」或「生活服务-摄影/扩印」类目）；观鸟数据展示（物种/地图/图表，数据由你录入）同理。多用户上传的共享相册则需个体户/企业主体。
3. **个体工商户主体是性价比最高的合规路径**：可微信认证（300 元/年）、可开支付、可选社交-笔记类目、认证时支持法人个人银行卡验证（无需对公账户）。
4. **域名 + HTTPS 是硬前提**：裸 IP 不能用于小程序任何网络请求（域名不得为 IP、必须 HTTPS、必须 ICP 备案）。后端迁移需先买域名并完成 ICP 备案（走腾讯云）。
5. **两套备案都要做**：① 域名 ICP 备案（腾讯云，给后端 API 域名用）；② 小程序备案（微信公众平台，2024 年起强制）。
6. **上线周期预估**：个人主体路径约 4–8 周；个体户/企业主体路径约 6–10 周（含网信办报备 7 个自然日，仅社交类目需要）。

## 1. 小程序注册流程

### 1.1 注册入口与步骤
入口：微信公众平台官网 mp.weixin.qq.com →「立即注册」→ 选「小程序」。
步骤：① 填邮箱（须未注册过公众平台/开放平台/企业号、未绑定个人号的邮箱）→ ② 邮箱激活 → ③ 选主体类型、填主体信息与管理员信息（管理员本人微信扫码）→ ④ 企业主体二选一验证（对公打款 / 微信认证）→ ⑤ 确认主体信息不可变更，完成注册。
来源：https://developers.weixin.qq.com/miniprogram/introduction/

### 1.2 主体类型
个人（18 岁以上国内实名微信用户）/ 企业 / 企业（个体工商户）/ 政府 / 媒体 / 其他组织。**主体一经注册不可变更（只能注销重注册）**，海外主体暂不支持。

### 1.3 个人主体 vs 企业主体关键差异
| 维度 | 个人主体 | 企业/个体户主体 |
|---|---|---|
| 微信认证 | **不能认证** | 可认证，300 元/次，有效期 1 年 |
| 微信支付 | **不支持** | 认证后可开通 |
| 手机号授权 | **不支持**（getPhoneNumber 仅「非个人主体且已认证」可用，0.03–0.04 元/次，有 1000 次体验额度） | 支持 |
| 开放类目 | 仅有限类目，**UGC 社交类目不开放** | 类目全开放（按资质） |
| 附近的小程序 | 不可用 | 可用 |
| 项目成员上限 | 15 个项目成员 + 15 个体验成员 | 未认证未发布 30/30；已认证未发布或未认证已发布 60/60；已认证已发布 90/90 |
| 登录方式 | wx.login（openid/UnionID）+ 头像昵称授权 | 同左 + 手机号 |

### 1.4 企业主体认证流程与费用
- **费用**：300 元/次（审核服务费，认证失败不退）；有效期 1 年，到期前 3 个月提醒年审，年审需重新缴费。
- **流程**：管理员扫码登录 MP → 微信认证 → 签协议 → 填企业资质（全称、营业执照、统一社会信用代码）→ 填对公账户 → **三选一验证**（对公打款 / 法人扫脸（绑本人银行卡的微信）/ 电子营业执照扫码）→ 填认证联系人 → 填发票 → 微信支付 300 元 → 第三方审核公司 1–5 个工作日审核（会电话核实）。
- **材料**：营业执照、对公账户信息、法人身份证、管理员身份证、《微信公众平台认证申请公函》（盖章）。
- **省钱点**：已有认证公众号可「复用公众号资质认证」免 300 元。
- **数量上限**：同一企业最多 50 个小程序；同一个体工商户最多 5 个。

### 1.5 账号/管理员/成员体系（与家庭协作相关）
- 一个微信号最多绑定为 5 个小程序的管理员；可成为 50 个小程序的项目成员、50 个体验成员。同一身份证最多注册 5 个个人小程序。
- 角色：管理员（1 个，最高权限）；项目成员（运营者/开发者/数据分析者，按角色授权）；体验成员（只能打开体验版）。
- 更换管理员需原管理员扫码授权。

## 2. 小程序备案（2024 年起强制）

### 2.1 法律依据与时限
- 依据：《反电信网络诈骗法》第 23 条、《互联网信息服务管理办法》第 4 条、工信部《关于开展移动互联网应用程序备案工作的通知》（2023-08-04，小程序全部纳入）。
- **未上架小程序自 2023-09-01 起须完成备案后才可上架**；存量小程序已在 2024-03-31 前完成，**逾期自 2024-04-01 起清退**。
- 备案免费（声称付费加急备案的第三方均为诈骗）。

### 2.2 备案流程（五环节）
**备案信息填写 → 平台初审 → 工信部短信核验 → 通管局审核 → 备案成功**
1. 填写：MP 后台「设置-小程序备案-去备案」。个人主体填姓名、身份证号、证件住所、通讯地址、负责人手机号/邮箱；小程序信息（名称、AppID、服务类目——**类目与实际功能不一致是驳回高发原因**）；负责人人脸核身。
2. 平台初审：1–2 个工作日。
3. 工信部短信核验：收到 12381 短信，**须 24 小时内**登录 beian.miit.gov.cn 完成核验。
4. 通管局审核：1–20 个工作日（驳回重提约 7 个工作日）。
5. 备案成功：下发备案号，自动展示在小程序「更多资料页」，无需自行悬挂。

### 2.3 个人主体备案所需材料
本人身份证、负责人本人实名手机号、常用邮箱、通讯地址、人脸核验、《互联网信息服务承诺书》在线确认。同一身份证最多备案 5 个小程序（社区口径）。

### 2.4 域名 ICP 备案（与小程序备案是两回事）
- 域名解析到境内服务器**必须 ICP 备案**，否则云厂商阻断访问；小程序 request 合法域名也要求已 ICP 备案。**两者都要做**。
- 流程（腾讯云）：备案小程序/PC 控制台 → 验证备案类型 → 填主体信息（须与腾讯云账号实名一致）→ 填网站信息（名称避免「中国/国家」等词）→ 证件拍照 + 视频/人脸核验 → 腾讯云初审（1–2 工作日）→ 工信部短信核验（24 小时）→ 省管局审核（20 个工作日内，常见 5–12 个）→ 下发备案号。
- 前提：域名已注册并实名认证；备案云资源为账号内服务器（部分省份要求购买时长 ≥3 个月）。
- **可备在他人服务器**：与服务器所有权无关，只与接入商有关——他人账号生成**备案授权码**即可。

## 3. 类目与资质（相册/图片/UGC/地图）

### 3.1 个人主体开放类目中与「相册、图片」相关的
| 一级 | 二级 | 三级 | 资质 | 适用范围 |
|---|---|---|---|---|
| 工具 | 工具 | 图片 | 无 | 图片/音频/视频**制作、剪辑** |
| 生活服务 | 生活服务 | 摄影/扩印 | 无 | 证件照、艺术照摄影、相片扩印等 |
| 工具 | 工具 | 信息查询 | 无 | 信息查询功能 |

注意官方在「工具-记账」等类目明确排除「用户自定义生成内容记录及分享」——平台对 UGC 类目边界很清晰。

### 3.2 「家庭共享相册」的类目定性（最关键）
微信官方对 UGC 的界定：**「用户随时随地自定义生成的内容（文字、图片等）发布与分享，且他人可见/访问」→ 需选「社交-笔记」类目**。
- 个人主体：社交-笔记**未开放**（官方答复原文见 §0）；
- 企业主体：申请社交-笔记需提交与注册主体一致的**《非经营性互联网信息服务备案核准》（ICP 备案）**；
- **首次提交社交-笔记类目的版本会进入网信办报备审核流程**（7 个自然日，无加急；未出结果可先「预上线」，但报备未通过需下架整改）。

**对本项目的含义**：
- 方案 A（个人主体可行）：相册 = 「你上传、家人看」，选「工具-图片」或「生活服务-摄影/扩印」，无 UGC、无报备；观鸟数据展示选「工具-信息查询」。
- 方案 B（多用户互相上传）：必须企业/个体工商户主体 + 社交-笔记类目 + ICP 备案 + 网信办报备 7 个自然日。
- 灰区提示：把 UGC 藏进工具类目提审属「类目与实际服务不符」，是官方明文的高频驳回/违规情形，不建议尝试。

### 3.3 UGC 资质
- 小程序侧：**必须接入微信内容安全 API**（§4.1），代码审核环节会检测，未接入无法通过。
- 牌照层面：普通家庭/熟人照片分享（非直播、非时政新闻、非视听节目、非网络文学出版）**不需要《网络文化经营许可证》《信息网络传播视听节目许可证》等前置审批**（若做直播/打赏/虚拟商品才涉及）。

### 3.4 地图相关
- **基础 `<map>` 组件（展示、markers、polyline、polygon/circle）无特殊类目或资质要求，个人主体可用**；个性化地图样式自 2023-06-29 起需付费；地图服务 API（搜索/路线/逆地理）商用可能收费。
- 观鸟场景建议：**只展示已记录的观鸟点（静态 markers）**，不调用 wx.getLocation → 规避定位权限审核（getLocation 需类目匹配 + 后台开通 + requiredPrivateInfos + 隐私指引 + 提审说明，审核趋严）。
- map 使用火星坐标系（gcj02）。
- 「map 组件需企业资质开通」的网络说法未找到官方依据，判定为不实，待核实。

## 4. 内容安全与审核

### 4.1 UGC 强制接口（均须服务端调用，前端直连会被拒审且泄露密钥）
| 接口 | 用途 | 频率限制 | 文件限制 | 结果方式 |
|---|---|---|---|---|
| `security.imgSecCheck` | 图片校验（鉴黄、敏感人脸） | 单 appId 2000 次/分钟、200,000 次/天 | 图片 ≤1MB，≤750×1334px | 同步，errcode 0=正常，87014=违规 |
| `security.msgSecCheck` | 文本校验（昵称、签名） | 历史口径 4000 次/分、200 万次/天（待核实） | 约 2500 汉字内（待核实） | 同步，result.suggest = pass/review/risky |
| `security.mediaCheckAsync`（v2.0） | 图片/音频异步校验 | 2000 次/分钟、200,000 次/天 | 单文件 ≤10MB | 异步：trace_id 匹配，30 分钟内推送消息接收服务器 |

1.0 版接口 2021-09-01 起停止更新，须用 2.0。**平台要求：提供 UGC 自定义发布功能的小程序必须接入内容安全 API，未接入无法通过代码审核。**

### 4.2 审核流程与时长
上传代码 →（可选）设为体验版 → 提交审核（重要页面配类目标签 ≤5 组；需登录的功能首次提审会被打回，第二次开放「测试账号」入口；建议附 30 秒内功能录屏）→ **代码审核 1–7 个工作日**（2024-12 官方口径）→ 涉及社交等报备类目的首次提审，微信侧通过后自动进入属地网信办报备（**7 个自然日**，无加急）→ 审核通过后**需管理员手动点「发布」**才上线。

### 4.3 加急审核
非个人主体每个自然年 3 次；个人主体每个自然年 1 次。加急预计 2 小时内完成（非个人 9:00-24:00、个人 9:00-21:00）；**网信办报备类目不支持加急**。

### 4.4 相册类常见被拒原因
- **类目与实际功能不符**（最致命）；
- **UGC 未接入内容安全 API**；
- 展示测试商品/内容、功能无法完整体验（需测试账号/录屏）；
- 登录不规范（首页强制登录、强制同意协议——应「先体验后登录」）；
- 名称/简介/头像与实际功能不符；
- 隐私合规：未填《用户隐私保护指引》。

### 4.5 体验版 vs 线上版
体验版：仅添加的体验成员（个人上限 15 人）扫码进入，无需审核；线上版：审核通过并手动发布后全部用户可见。

## 5. 技术要求清单（与发布相关）

### 5.1 服务器域名配置
- 位置：MP 后台 → 开发 → 开发设置 → 服务器域名。小程序**只能与指定域名通信**。
- 规则：① 只支持 https 与 wss；② **不能用 IP 或 localhost**；③ **域名必须 ICP 备案**；④ 端口规则严格（配了 `:8080` 就只能请求该端口，不配端口则不能带端口）；⑤ 每类域名最多 20 个；⑥ 不支持父域名；⑦ api.weixin.qq.com 不可配；⑧ AppSecret 只能存服务端。
- **修改次数**：MP 后台口径「一个月内最多申请 5 次」（API 口径每月 50 次仅第三方平台场景）→ 域名要一次配对。
- HTTPS 证书：有效、系统信任、域名一致、信任链完整、TLS ≥1.2；iOS 不支持自签名。
- 开发期可在开发者工具勾「不校验域名」跳过，仅限调试。

### 5.2 域名配置最小集
家庭相册最小集：**request + uploadFile + downloadFile 三类各配 1 个域名（可同一个域）**；如需实时推送再加 socket（wss）。

### 5.3 uploadFile/downloadFile 对鉴权设计的影响
- `wx.uploadFile`：强制 multipart/form-data POST；url 必须为 uploadFile 合法域名；filePath + name（必填，服务端按此 key 取文件）+ formData + header（**可自定义，但不能设 Referer**）。token 放 header 或 formData 均可。
- `wx.downloadFile`：GET，可自定义 header（除 Referer）。
- **私密照片鉴权的关键坑**：`<image src>` 不能带任何 header → 带鉴权的私有图片不能用 <image> 直接加载；应后端签发**带时效签名的公开 URL**（COS 预签名/CDN token），或 wx.downloadFile → 本地临时路径 → <image>。
- 并发上限 10，默认超时 60s。

### 5.4 体积限制
主包 ≤2MB、单分包 ≤2MB、**总计 ≤30MB**（服务商代开发 ≤20MB）。>1.5MB 考虑分包；静态资源 >200KB 放 CDN；`lazyCodeLoading: "requiredComponents"` 按需注入。**本项目前端单文件 56KB，重写后预计几百 KB～1MB，无压力。**

### 5.5 订阅消息（「通知家人有新照片」场景）
- 机制：选模板 → `wx.requestSubscribeMessage` 弹窗授权 → 服务端 `subscribeMessage.send` 下发。
- **一次性订阅**：用户每订阅 1 次可发 1 条；**长期订阅仅对政务、医疗、交通等特定类目开放，相册类用不了**。
- 含义：无法「静默推送」——每次通知需家人有过订阅动作。可行轻设计：打开时引导订阅一次，有新照片消耗 1 次额度；或用「小红点/时间戳 + 下拉刷新」替代。**这是机制性限制，非审核问题。**

### 5.6 隐私合规（相册功能必做）
- 自 2023-09-15 起，处理用户个人信息的小程序**必须先在 MP 后台填写《用户隐私保护指引》并审核通过**，用户同意后隐私接口才可调用。
- 相册相关需声明：「选中的照片或视频」（wx.chooseMedia）、「保存图片/视频到相册」（wx.saveImageToPhotosAlbum）。
- 授权弹窗不得默认勾选同意。

## 7. 待核实/风险点清单
1. **「家庭共享相册」是否 100% 落入社交-笔记**：官方对「他人可见的 UGC」定性明确，但「仅家庭成员可见、非公开传播」是否有更宽松口径未见官方明文——**建议以 MP 后台实际类目审核反馈为准**；风险备案方案是工具/摄影类目 + 仅管理员上传。
2. 服务器域名 MP 后台每月修改次数（5 次 vs 3 次说法不一）。
3. msgSecCheck 频率/长度限制（未取到官方页面）。
4. 个体户认证费以官方 300 元为准（低质量二手站的「30 元/年」不可信）。
5. 「map 组件需企业资质开通」未找到官方依据，按无需资质处理。
6. 加急额度付费购买的定价与开放范围（灰度中）。
7. 各省通管局对个人备案的补充材料要求因省而异。
